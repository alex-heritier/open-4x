# Synthetic source assets

Generated by `python3 tools/make_stub_assets.py` from original flat colours,
rectangles and silence. No installation files or Civ3-derived media are used.
The font consists only of an original rectangular ASCII glyph.

These synthetic media are dedicated to the public domain under CC0-1.0.

All fixed conversion stages are covered. Unit and leader reference names are
listed in `tools/stub_asset_refs.json`; this checkout lacks the requested Intro3
and TEST.SAV fixtures, so their specific coverage remains unverified. Refresh
with `python3 tools/make_stub_assets.py --biq FILE.biq` when available.

Run a rules-bearing BIQ with `--assets test-assets`. Conversion requires the
existing Pillow/ffmpeg prerequisites. Preserve any existing `assets/cache`
before converting: it is shared by every source root.
